# Security

## Supported versions

Security fixes apply to the `main` branch and the latest release, as maintained by the project. Older tags are not a separate support line.

## Reporting a vulnerability

Report vulnerabilities privately via GitHub Security Advisories. On the repository **Security** tab, choose **Report a vulnerability**.

Do not open a public issue for an unfixed vulnerability. There is no security email.

Maintainers acknowledge reports within 3 business days.

Maintainers must enable private vulnerability reporting in repository settings (**Settings → Advanced Security → Private vulnerability reporting**, or the current equivalent) so the Security tab accepts reports.
